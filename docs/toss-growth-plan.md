## ③ 프로모션 — '미니앱 구경하고 포인트 받기'
- 토스 **혜택 탭 → '관심 가는 앱 고르기'** 고정 자리에 노출. 사용자가 앱을 10초 보면 토스 포인트 지급
- 개발 없이 콘솔 설정만으로 가능, 출시된 앱만 가능(생애혜택 0.5.1 출시됨 ✓)
- 비용: 1명당 지급액(5원 또는 10원) × 인원. 비즈니스 월렛 **최소 5만 원** 충전(신용카드) → 10원이면 약 5,000명, 5원이면 약 10,000명
- 1명당 최대 N회(예: 2회), 재참여 대기 1시간, 하루 지급 한도·종료일 설정. 예산 다 쓰면 자동 종료, 남은 돈은 월렛으로 돌아옴
- 순서: ① 사업자 정보 등록(영업일 1~2일) → ② 정산 정보 등록(2~3일) → ③ 프로모션 약관 동의 → ④ 비즈 월렛 충전 → ⑤ 프로모션 등록 → 승인 영업일 약 2일
- 들어가는 길: 앱인토스 콘솔 → 대표 관리자 로그인 → 워크스페이스 → 미니앱 → 왼쪽 메뉴 '프로모션' → '미니앱 구경하고 포인트 받기'
- 솔직한 평가: 포인트 받으러 온 사람이라 그냥 나가는 경우가 많음. 그래도 처음 보는 사람이 크게 늘고, 그중 부모님 혜택이 필요한 사람은 남음 → **5만 원으로 작게 시험 → 대시보드(혜택 탭 진입 → 클릭 → 포인트 획득, 신규/기존 사용자)로 남는 비율 보고 결정**
- ⚠ 돈이 드는 일이라 **사장님 허락 전에는 진행하지 않음**
